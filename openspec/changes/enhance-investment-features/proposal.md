## Why

当前投资理财模块存在几处影响日常使用的缺口：持仓现价需逐只手动填、持仓没有按基金系列归类、永久组合与定投对用户录入依赖过重、定投只有纳斯达克100单一标的且均线不全、缺少每日定投自动记账、且版本升级存在清空历史数据的风险。本次变更把这些缺口一次性补齐，让投资模块在手机日常使用中做到「打开即用、数据正确、自动驱动」。

价格获取方向已与用户确认：**保留并增强现有自动拉取**（Yahoo + 东方财富 + 构建时打包行情），页面打开自动触发、提供手动按钮、失败时保留原数据并明确提示，同时保留手动覆盖能力。

## What Changes

### 投资组合页（持仓 + 现价 + 分类）
- **现价自动拉取**：进入投资页时自动触发拉取，提供「拉取最新行情」按钮；成功后自动更新现价与持仓总额；保留手动编辑现价能力，手动值可覆盖自动值。拉取失败/接口不可用时**保留原有数据，绝不清空**，并给出明确失败提示。
- **资产分类标签**：每条持仓可打标签——纳斯达克100 / 标普500 / 债券 / 红利（及其他）。投资页顶部增加分类切换 Tab，选中后聚合展示该类别下全部持仓及小计市值。

### 永久投资组合页（自动归类 + 目标偏差）
- 实际占比**完全由持仓数据自动计算**，无需用户手填市值；用户仅设置目标占比。
- 通过持仓的资产类别（股票/债券/现金/黄金）自动汇总，结合自动拉取的现价得到最新市值，自动计算实际占比与目标占比的偏差，超阈值提醒再平衡。

### 定投模块（多标的 + 均线 + 每日自动）
- **纳斯达克100**：保留原有 MA120/MA250 逻辑，**补充 MA180 均线**（图表与档位均可呈现）。
- **新增标普500定投**：均线、偏离档位、周建议交互与纳斯达克100完全对齐，独立配置独立行情。
- **每日定投自动记账**：新增「每日定投」配置项——选择定投基金（持仓）+ 每日金额。**网页打开时校验日期**，若当日尚未执行则自动新增一笔买入记录（按最新已知价折算份额），同步更新对应持仓数量与资产总额。浏览器关闭期间不执行（无后台服务，符合浏览器限制，如实呈现）。

### 数据持久化与升级迁移
- 版本升级后历史数据完整保留。通过 IndexedDB schema 版本升级（v1→v2）在 `upgrade()` 中**增量新增** store/index/字段，**绝不重建已存在 store**，确保旧数据不被清空。每日定投执行状态用「最近执行日期」幂等判定，重复打开不重复记账。

## Capabilities

### New Capabilities
- `investment-portfolio`: 持仓现价自动拉取（失败安全 + 手动覆盖）与资产分类标签（纳斯达克100/标普500/债券/红利）按类聚合查看。
- `permanent-portfolio`: 永久投资组合由持仓数据自动汇总实际占比、用户设目标占比、自动算偏差并提醒。
- `dca-strategy`: 多标的智能定投（纳斯达克100 补 MA180 + 新增标普500）与每日定投打开即自动记账。
- `data-migration`: IndexedDB schema 升级迁移，版本升级后历史数据完整保留。

## Impact

- **存储层**：`src/repos/db.ts` 的 `SCHEMA_VERSION` 1→2，`upgrade()` 增加 `version` 分支增量迁移（新增 `dailyDcaConfigs` store、`holdings` 增加 `category` 索引等），保留所有现有 store 与数据。新增 `dailyDcaConfigRepo`。
- **类型**：`src/types/portfolio.ts`（`Holding` 增 `category`）、`src/types/dca.ts`（新增 `DailyDcaConfig`、`IndexData` 支持多 symbol）、`src/types/settings.ts`（如需记录每日定投最近执行日）。
- **行情层**：`src/lib/yahoo.ts` 增加标普500（^GSPC）拉取与构建时打包；`scripts/fetch-nasdaq.cjs` 扩展为同时抓取 NDX + GSPC；`src/lib/ma.ts` 已支持任意周期，复用 `rollingMA(period=180)`。
- **定投层**：`src/lib/dca.ts`、`src/stores/dca.ts` 重构为多标的数据结构；新增 `src/lib/dailyDca.ts` 每日定投记账与幂等校验。
- **页面**：`src/pages/Portfolio.vue`（自动拉取 + 分类 Tab）、`src/pages/Permanent.vue`（确认自动驱动）、`src/pages/Dca.vue`（多标的切换 + MA180）、新增每日定投配置入口。
- **测试**：MA180 计算、分类聚合、永久组合偏差、每日定投幂等记账（同日重复打开不重复）、schema 迁移保留旧数据。
- **兼容性**：纯前端、无后端；IndexedDB 已天然持久化（刷新/重开不丢），本次重点是升级迁移安全与幂等。
