## Why

上一轮 `enhance-investment-features` 上线后，线上实测暴露三个让投资模块实际不可用的缺陷：
1. **行情自动拉取在手机浏览器全失败**：用户持有的是中国场外公募基金（如 `006260` 汇添富红利增长、`019261` 富国恒生红利），现价全显「—」，提示「行情拉取失败」。根因是 Yahoo/东方财富**股票**接口在浏览器跨域（CORS）被拦、公共代理在线上不稳定——纯前端对**中国基金净值**没有可用源。
2. **基金全被分到「其他」**：分类需手动选、默认「其他」，没有按基金名称自动识别。用户 16 只基金（多为红利类）全落进「其他」，分类 Tab 形同虚设。
3. **永久组合全 ¥0.00**：根因有二——① 无净值→无市值→被过滤；② 更关键的 bug：基金 `type` 默认 `etf`，而永久组合只认 `stock/bond/cash/gold`，`etf` 被直接排除，所以**永远读不到用户的基金**。

本次变更修复这三点，让投资模块在线上真正可用。方向已与用户确认：**尽力自动拉取**，且对**后续新增的基金也通用**。

## What Changes

### 1. 基金净值数据源（中国场外基金，JSONP 绕过 CORS）
- 新增**天天基金 JSONP 拉取**：对 6 位基金代码，用 `fundgz.1234567.com.cn` 的 JSONP 接口拉「当日估算净值 / 最近单位净值」。JSONP 走 `<script>` 标签，**不受浏览器 CORS 限制**，在 GitHub Pages 线上可用。
- **通用 & 面向新增**：任意用户新加的 6 位基金代码都会自动尝试该源；美股代码（字母）仍走 Yahoo 代理链。无需逐只配置。
- **尽力而为 + 绝不显示错误值**：拉取的是估值/净值（场外基金每天一个值，非实时成交价），失败或无数据时**保留原值不清空**并明确提示，绝不写入 0 或错误价。优先用真实单位净值 `dwjz`，缺则用估算值 `gsz`。

### 2. 持仓自动分类（按名称/代码推断）
- 新建/编辑持仓时，**按名称与代码关键词自动推断 `category`** 并预填（用户可改）：
  - 含「红利/股息」→ 红利；含「标普/S&P/500/SPX/SPY」→ 标普500；含「纳指/纳斯达克/QQQ/NDX」→ 纳斯达克100；含「债/bond」→ 债券；否则 → 其他。
- 提供「**一键重新自动分类**」按钮，对已有持仓（如当前全在「其他」的 16 只）批量重算分类。

### 3. 永久组合正确读取持仓（category → 资产类别映射）
- 永久组合的实际占比聚合**改用 `category` → 资产类别映射**（而非仅 `type` 字段）：
  - 纳斯达克100 / 标普500 / 红利 → **股票**
  - 债券 → **债券**
  - 其他 → 按其 `type`（stock/bond/cash/gold 各归各类；`etf`/`crypto` 归股票）
- 由此用户的红利/纳指/标普基金自动计入「股票」、债券基金计入「债券」，永久组合能正确显示现有持仓比例与偏差。配合净值拉取（有净值→有市值），彻底解决 ¥0.00。

## Capabilities

### New Capabilities
- `fund-quote-source`: 中国场外基金净值/估值的尽力拉取（JSONP 绕过 CORS），通用覆盖任意 6 位基金代码（含后续新增），失败保留原值、绝不写错误价。

### Modified Capabilities
- `investment-portfolio`: 新增按名称/代码自动推断分类 + 一键批量重分类（在上一未归档变更 `enhance-investment-features` 中定义，本次新增自动分类行为）。
- `permanent-portfolio`: 实际占比聚合规则改为 `category → 资产类别` 映射，使基金正确计入股票/债券类（同上，本次修改聚合行为）。

## Impact

- **数据源**：新增 `src/lib/fundQuote.ts`（JSONP 封装，串行化避免回调名冲突）；`src/lib/yahoo.ts` 的 `fetchHoldingPrice` 路由更新——6 位数字代码走基金 JSONP，字母代码走 Yahoo 代理链。
- **分类**：新增 `src/lib/category.ts`（`inferCategory(name, symbol)` 关键词推断）；`Portfolio.vue` 新建表单调用预填 + 新增「一键重新自动分类」按钮（批量 `holdingRepo.put`）；类型 `HoldingCategory` 复用。
- **永久组合**：`src/lib/permanent.ts` 聚合改为接受 `category` 并映射；`src/stores/permanent.ts` 传入 category；`HoldingForPerm` 增 `category`。
- **兼容**：无 schema 变更（category 字段已存在）；旧持仓 category 缺省走 type 回退映射，不影响数据。
- **测试**：JSONP 封装的解析与超时降级（mock script 注入）、`inferCategory` 关键词各分支、category→资产类别映射各分支、一键重分类后聚合正确。
- **约束说明**：`fundgz.1234567.com.cn` 为第三方免费接口、非官方承诺，可能限流/偶发不可用；按「尽力 + 失败保留」设计，符合用户「宁可保留也不给错值」的要求。
