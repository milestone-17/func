## 三、`?src=` 归因参数约定

### 命名规范
- 格式：`渠道-批次`，全小写，用连字符分隔。如 `tz-group1`（理财群第1批）、`dev-group2`（程序员群第2批）。
- 渠道前缀约定：`tz-` = 理财/投资群，`dev-` = 程序员/技术群，`xhs-` = 小红书，`wb-` = 微博（后续扩展按前缀类推）。
- 每换一个群、或同一群隔周再发，批次号 +1；一批发送共用同一参数，便于整批统计。

### 完整链接格式
```
https://milestoneluo.top/func/?src=xxx
```
示例：`https://milestoneluo.top/func/?src=tz-group1`

### umami 后台查看方法
1. 登录 https://milestoneluo.top/stats/login （账号 admin，密码见服务器 `/home/ubuntu/.umami_admin_pass`，首次登录密码 umami、应已改密）。
2. 进入对应网站（milestoneluo.top）→ 「页面」(Pages) 报表。
3. 在页面 URL 过滤框输入 `?src=tz-group1`（或 `src=tz-group1`），即可看到带该参数的 pageview 数——即该群带来的打开次数。
4. 对比「访问者」中的 UV/会话时长可进一步判断质量；多批次对比用 `?src=tz-group` 前缀过滤看汇总。
5. 注意：umami 记录的是落地页 `/func?src=xxx` 的 pageview，回测/通道/永久组合等子页面访问可在「页面」报表按 `/dca`、`/channel`、`/permanent` 过滤，交叉判断哪个功能留住人。

## 四、信号判定标准

### 信号一览

| 信号 | 判定条件 | 动作 |
| --- | --- | --- |
| ✅ 素材成立 | 24h 内 ≥3 人主动询问工具/使用方式 | 该素材方向**加量**：换同系列变体、扩到同类型其他群 |
| 🔄 换素材 | 24h 内 0 回复 **且** umami 无对应 `?src` 访问 | 换素材（A→B→C 轮换）或换渠道 |
| 🚨 警戒 | 有人反馈「打不开 / 证书告警」 | **立即停止发群**，先解决 HTTPS（当前自签证书是已知问题，等 certbot 正式证书就绪后再恢复投放） |

### 补充判定
- 24h 内有回复但 umami 访问数为 0 → 话术吸引人但链接/环境有问题，先自查链接可达性，再复投一次。
- 24h 内有访问（pageview ≥3）但无人回复 → 素材能引流但话术缺互动钩子，下一批在话术里加具体提问（如「这个拟合你们觉得能跑赢定投吗」）。
