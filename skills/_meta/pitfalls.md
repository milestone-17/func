# 踩坑记录（P-<短hash> 编号，与 git fix 提交一一对应）

> 来源纪律：每个 fix 提交合并后必须在此登记一行；hash 必须真实存在（校验器会 git 验证）。
> 用途：AI 开发前扫一遍相关模块的坑，避免重蹈覆辙。

## auth / 登录态

### P-e322422 守卫幂等短路竞态误踢登录
- 症状：刷新/导航后掉登录。根因：auth init 非幂等，并发时短路分支误清 token
- 规则：init 必须共享同一 Promise（C-07）

### P-42b253a / P-5405c58 WebView cookie 竞态掉登录
- 症状：WebView 内偶发掉登录。根因：cookie 未就绪即探活
- 规则：首屏探活失败放行守卫，页面级 401 兜底（C-07）

## 数据一致性

### P-93bbd21 持仓数量翻倍
- 症状：投资持仓数量×2。根因：computePosition 有交易时仍叠加持仓种子
- 规则：有交易时以交易为准（C-01）

### P-41e2f17 / P-458ba4f 配置 id 跨用户冲突 409
- 症状：保存定投配置无反应（后台 409）。根因：DcaConfig/DailyDcaConfig id 全局唯一未按用户隔离
- 规则：配置表 id/唯一索引带 userId（C-03）

### P-fabec89 HTTP 部署下保存全挂
- 症状：HTTP 访问时所有保存失败。根因：crypto.randomUUID 需安全上下文
- 规则：浏览器 API 必须降级（C-04）

### P-3644df4 无目标基金的定投不同步账本
- 症状：仅记账模式定投执行后账本缺记录。根因：执行同步只处理有 DcaFund 的情况
- 规则：无目标基金的执行也要补账（C-01 相关）
